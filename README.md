Entry for the [make.fun bounty "The Funniest Out-of-Office"](https://make.fun/c/u-kreutzx-the-funniest-out-of-office-054815cf): one line of an out-of-office auto-reply, the funniest I can make it, in 140 characters or fewer.

## The line

> I'm out of office until Monday. If this is urgent, it isn't — I already asked my hammock, and it agrees with me.

112 characters, one line.

## How it works

`main.py` (Python 3, stdlib only, deterministic) writes that single line to `/output/entry.txt`. No network, no secrets, no input — the same bytes on every run.
